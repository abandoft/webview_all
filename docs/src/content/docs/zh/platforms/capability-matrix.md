标记说明：

| 标记 | 含义 |
| --- | --- |
| 完整 | 由平台引擎或强类型桥完整实现。 |
| 有限制 | 已实现，但有明确浏览器、系统或引擎限制。 |
| 不支持 | 当前不可用，通常会抛错或按文档 no-op。 |
